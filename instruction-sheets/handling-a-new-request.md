# Handling a new request

Use this when a new email, text or request comes in.

1. Read the newest message in the conversation.
2. Check the to-do list for a job that's already about the same thing.
3. Found one? Update it.
4. Nothing there? Add a new line and pick one helper to own it.
5. Send that helper a short note: who it's for, what's needed, when it's due and where it's on the list.
6. Receipts and bills go to the bookkeeping helper.
7. Never delete email, and never say you checked something you couldn't open.
