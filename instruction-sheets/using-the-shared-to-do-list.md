# Using the shared to-do list

Use this any time you start, update, hand off or finish a job.

1. Look at the to-do list first. Is this job already on it?
2. If it is, update that line. Don't add a second copy.
3. If it isn't, add one line with: the job, who is doing it, what happens next, when it's due and where it came from.
4. Keep "what happens next" clear, like "Mail sorter drafts a reply."
5. Handing off? Change "who is doing it" to the next helper and leave a short note.
6. Add links to finished work as soon as you have them. Never pretend something exists.
7. Anything that sends, posts or spends money waits for my yes.
8. Only mark it done when you can show proof.
